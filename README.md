# TimeCast

Um simples serviço de streaming de podcast onde você pode ouvir seus podcasts favoritos, descobrir novos e até mesmo fazer upload do seu!

## Principais características

* **Navegue e pesquise:** Encontre facilmente podcasts por título.
* **Detalhes do podcast:** Visualize informações detalhadas sobre cada podcast, incluindo a lista de episódios.
* **Ouça episódios:** Reproduza episódios de podcast diretamente no aplicativo.
* **Autenticação de usuário:** Registre-se e faça login para acessar recursos personalizados.
* **Favoritos:** Marque seus episódios favoritos para ouvi-los mais tarde.
* **Envio de episódios:** Faça upload de seus próprios episódios de podcast.

## Tecnologias utilizadas

* **Back-end:** Java com Spring Boot
* **Gerenciamento de banco de dados:** Spring Data JPA com Hibernate
* **Banco de dados:** H2 (em memória)
* **Front-end:** HTML, CSS, JavaScript e Bootstrap
* **Gerenciamento de compilação:** Maven
